# 🚀 Quick Start Guide - Jatin Electronics Website

Your professional website is ready to launch! Follow these steps to get online.

## ⚡ 30-Second Deployment (Vercel - Recommended)

### Step 1: Create GitHub Account (if you don't have one)
- Go to [github.com](https://github.com)
- Sign up with email
- Verify email

### Step 2: Upload Website to GitHub
```bash
# Open terminal/command prompt in your website folder

# Initialize git
git init

# Add all files
git add .

# Create first commit
git commit -m "Launch Jatin Electronics website"

# Create new repository on GitHub (don't initialize with README)
# Then run:
git remote add origin https://github.com/YOUR_USERNAME/jatin-electronics.git
git branch -M main
git push -u origin main
```

### Step 3: Deploy on Vercel (1 minute)
1. Go to [vercel.com/dashboard](https://vercel.com/dashboard)
2. Click "Add New..." → "Project"
3. Select "Import Git Repository"
4. Paste your GitHub repo URL
5. Click "Import"
6. Click "Deploy"
7. **Done! Your site is live!** 🎉

### Step 4: Connect Your Domain (Optional - 5 minutes)
1. In Vercel dashboard, click your project
2. Go to "Settings" → "Domains"
3. Add your domain (e.g., jatinelectronics.com)
4. Update your domain's DNS settings (Vercel shows the exact steps)

## 🚨 Common Issues & Solutions

**Issue:** Website looks different on my phone
- **Solution:** Refresh page, clear cache (Ctrl+Shift+Delete)

**Issue:** Links don't work
- **Solution:** Check file names match (index.html, products.html, about.html)

**Issue:** Images don't load
- **Solution:** Add images to `/images` folder, update paths in HTML

**Issue:** Contact form doesn't send emails
- **Solution:** Use Formspree (see README.md) or hire developer for backend
